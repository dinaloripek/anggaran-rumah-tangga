Anggaran Rumah Tangga — situs anggaran keluarga Prasetyo untuk November 2026: ringkasan pemasukan Rp 12.500.000 dan pengeluaran per 26 November, anggaran 8 kategori dengan bilah progres, daftar pengeluaran yang bisa ditambah dan disaring, tiga tujuan tabungan, dan laporan 6 bulan dengan grafik. Lima halaman lewat rute hash, semua tombol berfungsi, data tersimpan di localStorage, tanpa satu pun permintaan jaringan. Dibangun sebagai situs statis tanpa pustaka.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
